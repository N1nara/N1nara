N1NARA - CATALOGO COM PEDIDO PELO WHATSAPP

Esta versao funciona no GitHub Pages sem servidor, sem banco de dados, sem login e sem pagamento online.

Como publicar:

1. Abra esta pasta.
2. Envie todos os arquivos para a raiz do repositorio N1nara no GitHub.
3. O arquivo index.html precisa ficar na raiz.
4. Se a sua logo estiver no GitHub com o nome Logo N1.png, ela sera usada automaticamente.

Arquivos importantes:

- produtos.js: dados, preços, opções e textos dos produtos.
- config.js: Instagram, WhatsApp e link manual do Reels.
- carrinho.js: carrinho salvo no navegador com localStorage.
- produto-page.js: paginas individuais de produtos.
- identificacao.js: idade, QR Code e localizacao para Pet, Pessoa e Bagagem.

O pedido fica salvo apenas no navegador do cliente ate ser enviado pelo WhatsApp.
O site nao armazena pedidos em painel administrativo.
O e-mail nao aparece nas paginas publicas.

Para alterar preços, textos ou opções, edite apenas o arquivo produtos.js.

Reels do Instagram:

No arquivo config.js, cole o link normal do Reels no campo latestPostUrl.

Exemplo:

latestPostUrl: "https://www.instagram.com/reel/CODIGO_DO_REELS/"

Nao precisa adicionar /embed manualmente.
Se o Instagram bloquear a exibicao dentro do site, o site mostra um botao para assistir diretamente no Instagram.
